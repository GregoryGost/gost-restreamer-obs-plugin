GOST Restreamer — установка и обновление плагина для OBS
====================================================

Для кого эта инструкция
----------------------
Для Windows 10 или Windows 11, 64-разрядной OBS Studio 33.0.1.
Устанавливать программы для сборки плагина не нужно: используйте готовый ZIP.
Для работы плагина также нужен отдельно настроенный сервер GOST Restreamer.

1. Подготовьте файлы
-------------------
1) Скачайте ZIP-архив плагина для Windows x64.
2) Нажмите на архив правой кнопкой мыши и выберите «Извлечь всё…».
3) Откройте полученную папку. В ней должна быть папка
   gost-restreamer-obs-plugin. Внутри неё находятся:

   gost-restreamer-obs-plugin.dll
   data
     locale
       ru-RU.ini
       en-US.ini

   DLL — сам плагин, data — его вспомогательные файлы.
   Копируйте папку gost-restreamer-obs-plugin целиком.

2. Закройте OBS
--------------
Завершите текущую трансляцию и запись, затем закройте OBS через «Файл → Выход».
Если OBS свёрнута в область значков рядом с часами, откройте её и выберите «Файл → Выход».
Плагин устанавливается и обновляется только при полностью закрытой OBS.

3. Выберите свой способ установки OBS
------------------------------------

ОБЫЧНАЯ УСТАНОВКА OBS
Если вы устанавливали OBS обычным установщиком:

1) Нажмите на клавиатуре Windows + R.
2) Вставьте эту строку и нажмите Enter:

   %ProgramData%

3) Откройте папку obs-studio. Если её нет, создайте папку с именем obs-studio.
4) Внутри откройте папку plugins. Если её нет, создайте папку с именем plugins.
5) Скопируйте в plugins папку gost-restreamer-obs-plugin из распакованного ZIP.

Итоговый путь к файлу плагина должен быть таким:

%ProgramData%\obs-studio\plugins\gost-restreamer-obs-plugin\gost-restreamer-obs-plugin.dll

Рядом с DLL должна находиться папка data. Дополнительная вложенная папка
с тем же именем gost-restreamer-obs-plugin не нужна.

ПЕРЕНОСИМАЯ (PORTABLE) OBS
Если вы запускаете специально подготовленную переносимую OBS из папки:

1) Откройте корневую папку этой OBS — ту, где находятся папки bin и data.
2) Откройте в ней папку plugins. Если её нет, создайте её.
3) Скопируйте туда папку gost-restreamer-obs-plugin из распакованного ZIP.

Итоговый путь относительно папки переносимой OBS:

plugins\gost-restreamer-obs-plugin\gost-restreamer-obs-plugin.dll

Для portable OBS используйте именно её собственную папку plugins.

4. Проверьте, что плагин появился
-------------------------------
1) Запустите OBS.
2) Откройте меню «Сервис» (Tools в английском интерфейсе).
3) Выберите «GOST Restreamer». Должно открыться окно управления плагином.
4) В меню «Док-панели» (Docks) включите панель GOST Restreamer, если она скрыта.

При повторном выборе «Сервис → GOST Restreamer» открывается то же окно.
Язык и оформление плагина следуют настройкам OBS.

5. Первое подключение
--------------------
1) В окне GOST Restreamer откройте раздел «Настройки».
2) Введите адрес API вашего сервера, полученный при его настройке.
   Пример формы адреса: http://192.168.1.100:8080
   Не дописывайте /api/v1 в конец адреса.
3) Нажмите «Сохранить» и дождитесь подключения.
4) Выберите нужный поток в верхней части панели GOST Restreamer.

Адрес API нужен плагину для управления сервером. Адрес трансляции и ключ
для отправки видео задаются отдельно в штатных настройках трансляции OBS.
Само подключение плагина к серверу не начинает эфир.

Как обновить плагин
------------------
1) Скачайте и распакуйте новый ZIP, как описано в пункте 1.
2) Завершите трансляцию и запись, полностью закройте OBS.
3) Откройте ту же папку plugins, куда устанавливали плагин.
4) Скопируйте новую папку gost-restreamer-obs-plugin поверх старой.
5) При запросе Windows выберите замену файлов в папке назначения.
   Заменяются и DLL, и файлы внутри data.
6) Не удаляйте профили, коллекции сцен и каталог конфигурации OBS.
7) Запустите OBS и снова откройте «Сервис → GOST Restreamer».
   Версия сборки показана внизу панели плагина.

Если Windows сообщает, что файл используется, отмените копирование,
полностью закройте оставшийся экземпляр OBS и повторите обновление.

Если пункта GOST Restreamer нет в меню
------------------------------------
1) Убедитесь, что используете 64-разрядную OBS Studio 33.0.1.
2) Проверьте путь: DLL лежит прямо в папке gost-restreamer-obs-plugin,
   а data находится рядом с ней. Папок bin\64bit внутри папки плагина нет.
3) Проверьте, что копировали файлы в нужную OBS: обычная и portable OBS
   используют разные папки plugins.
4) Полностью закройте и снова запустите OBS.
